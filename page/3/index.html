🛠 题型模板与核心思路

题型归类：二叉树遍历序列还原 + 层序输出
核心逻辑：

  1. 后序定根：后序序列的最后一个元素一定是当前子树的根节点。
  2. 中序分左右：在中序序列中找到根节点，其左侧为左子树的中序区间，右侧为右子树的中序区间。
  3. 区间映射：根据左子树节点数量，将后序序列划分为左、右子树的后序区间。
  4. 递归构建：对左右子树区间重复上述过程。
  5. 层序输出：构建完成后使用 BFS（队列）按层访问，或直接利用完全二叉树数组下标映射（根为1，左2*i，右2*i+1）记录层序结果。

  1. 前缀和转化：预处理 sum[i] = sum[i-1] + a[i]，任意子段 $[l, r]$ 和为 sum[r] - sum[l-1]。
  2. 滑动窗口：枚举右端点 $i$，合法的左端点前缀下标 $j$ 需满足 $i - m \le j < i$。

📝 题意极简概括

💡 解题思路拆解（金牌教练视角）

  1. 发现单调性（破题关键）

    • 当 $W$ 增大时，满足 $w_j \ge W$ 的矿石只会变少或不变。
    • 因此，每个区间的“个数”和“价值和”均单调不增，乘积 $y_i$ 单调不增，总和 $Y(W)$ 也单调不增。
    • 单调性 $\Rightarrow$ 可使用二分答案确定 $W$ 的搜索方向。

  2. 暴力计算的瓶颈与优化

    • 若对每个 $W$ 暴力遍历区间计算，复杂度为 $O(m \cdot n \cdot \log(\max w))$，必然超时。
    • 观察到区间查询是静态的，且每次判断条件仅与 $W$ 有关。可使用前缀和预处理：
      • pre_cnt[i]：前 $i$ 个矿石中重量 $\ge W$ 的个数
      • pre_val[i]：前 $i$ 个矿石中重量 $\ge W$ 的价值和
    • 预处理 $O(n)$，单次区间查询 $O(1)$。总计算复杂度降至 $O(n+m)$。

  3. 二分策略设计

    • 搜索范围：$L=0$（所有矿石都满足），$R=\max(w_i)+1$（没有矿石满足，$Y=0$）。

      • 若 $Y \ge s$：说明当前 $W$ 偏小，检验值偏大，需增大 $W$ $\Rightarrow$ L = mid + 1
      • 若 $Y < s$：说明当前 $W$ 偏大，检验值偏小，需减小 $W$ $\Rightarrow$ R = mid - 1
    • 关键细节：最优解不一定恰好等于 $s$，因此每次二分都要更新答案 ans = min(ans, abs(s - Y))。

    • 时间：$O((n+m) \log (\max w)) \approx 4\times 10^5 \times 20 = 8\times 10^6$，轻松通过 1s 限制。

数学几何

📖 1. 题意概括

给定 $N$ 条直线，满足任意三条直线不共点。通过调整直线之间的平行关系，求这些直线在平面上可能形成的不同交点总数的种类数（即有多少种可能的交点数量）。

  • 数据范围：$1 \le N \le 25$
  • 核心考点：平行线分组思想、递归状态枚举、布尔数组标记可达状态。

🧠 2. 核心解题思路

① 数学模型转化

交点数仅由直线的平行关系决定。若将 $N$ 条直线划分为若干组平行线，设各组大小为 $a_1, a_2, \dots, a_k$（$\sum a_i = N$），则总交点数为：
$$ \text{交点数} = \sum_{1 \le i < j \le k} a_i \times a_j $$
因为不同组的直线必相交，同组内直线平行不相交。

② 递归状态定义

直接枚举划分方案较繁琐，可采用增量递归思想：

  • 状态参数：g(剩余直线数 n, 当前已累积交点数 k)
  • 转移策略：每次从剩余 n 条直线中拿出 r 条作为新的一组平行线（$1 \le r \le n$）。
    • 这 r 条平行线必与剩下的 n-r 条直线各产生一个交点，贡献 r * (n-r) 个交点。
    • 剩下的 n-r 条直线继续递归处理。
  • 边界条件：n == 0 时，说明所有直线已分配完毕，此时累积的交点数 k 是一种合法方案，标记为可达。

③ 复杂度分析

  • 最大交点数：当所有直线两两相交时，交点数最大为 $\binom{25}{2} = 300$，布尔数组开 11000 绝对安全。
  • 搜索树规模：等价于整数划分问题 $P(25)$，状态数极少，递归深度 $\le 25$，运行时间远低于 $1\text{ms}$。

📌 题型分类：数论 + 因数统计 + 单调性优化
📌 难度评级：⭐⭐⭐（蓝题）
📌 核心思想：逆向思维 + 因数贡献统计 + 答案单调性

📋 题意概括

关键转化：

「k 个数的公约数」⇔「这 k 个数都含有某个公共因数」
因此：统计每个因数在多少个数中出现，出现 ≥k 次的因数中最大的那个，就是选 k 个数时能达到的最大 GCD

💡 解题思路详解

❌ 暴力思路（不可行）

✅ 正解思路（因数贡献法）

第一步：统计每个因数的出现次数

  • 对每个数 x，枚举 [1, √x] 的所有因数 i
  • 若 i | x，则 i 和 x/i 都是 x 的因数，对应计数器 +1
  • 注意：当 x 是完全平方数时，√x 只计一次

第二步：利用答案的单调性

第三步：输出答案

  • 对于每个 k ∈ [1,n]，找到最大的 d 满足 c[d] ≥ k
