📝 算法错题整理 | MC0563 襄子惜义放豫让

📖 题意概括

给定 $n$ 个长度均为 $m$ 的字符串。定义 $f(s,t)$ 为使两串完全相同所需的最少修改次数（实际等价于两串的汉明距离，即对应位置字符不同的个数）。要求计算所有 $\frac{n(n-1)}{2}$ 对字符串的 $f(s_i,s_j)$ 之和。数据范围满足 $n \times m \le 10^6$。

🧠 整理思路

直接枚举所有字符串对并逐位比较的时间复杂度为 $O(n^2 m)$，在 $n \times m \le 10^6$ 的限制下极易超时。
正解思路：贡献法（按列统计）

  1. 转换视角：不枚举“字符串对”，改为枚举“字符串的列（位置）”。
  2. 对于第 $j$ 列，统计 $26$ 个小写字母各自的出现次数 $cnt[c]$。
  3. 该列对总答案的贡献 = 该列中字符互不相同的字符串对数。
    • 该列总对数：$\binom{n}{2} = \frac{n(n-1)}{2}$
    • 该列相同字符对数：$\sum_{c=’a’}^{‘z’} \binom{cnt[c]}{2} = \sum \frac{cntc}{2}$
    • 贡献值 = 总对数 - 相同对数
  4. 遍历 $m$ 列累加贡献即可，时间复杂度降至 $O(nm)$，完美契合时限。

❌ 原代码错误分析

学生原代码逻辑正确，但存在严重的时间复杂度瓶颈：

错误/隐患说明：

  1. 复杂度爆炸：三重嵌套循环导致时间复杂度为 $O(n^2 m)$。当 $n=1000, m=1000$ 时，循环次数高达 $10^9$ 量级，远超 1 秒时限（通常评测机 $10^8$ 次/秒），必然 TLE。
  2. 未利用题目限制特性：题目给出 $n \times m \le 10^6$，是典型的提示信号，暗示正解复杂度应为 $O(nm)$。原代码仅做了朴素模拟，未进行降维或贡献法优化。

✅ 注释后正确代码（紧凑无多余空行）

📦 题型模板代码与总结

🔑 通用模板（求所有两两组合的某项差异和）

💡 避坑指南

  1. 识别题型：遇到“求所有 $\binom{n}{2}$ 对字符串/数组的某种距离/差异之和”时，第一时间放弃 $O(n^2)$ 暴力，改用按位/按属性独立计算贡献。
  2. 防溢出细节：组合数计算 $\frac{n(n-1)}{2}$ 中间结果可能超过 int 范围，务必写成 1LL * n * (n-1) / 2。
  3. 题意转化：本题中“最少修改次数使两串相同”本质就是统计不同位置的数量（汉明距离），理解这一转化能大幅降低思维负担。

📝 算法错题整理 | MC0565 豫让伏桥修暗器（二次提交版）

📖 题意概括

给定 $n$ 件暗器（编号 $1 \sim n$，价值 $v_i$）和 $m$ 个修复工具。每个工具限制可修复暗器的 编号下限 $t$ 和 价值上限 $z$。每件暗器与每个工具均 只能使用一次。求修复暗器的 总价值最大值。
📌 数据范围：$\sum n, \sum m \le 3 \times 10^5$。核心考点：离线贪心 + 状态去重 + 平衡树维护。

🔍 代码诊断（错误分析）

本次提交在逻辑与语法层面存在多处致命问题，直接导致编译失败或严重超时（TLE）：

错误位置 代码片段 问题分析
1. 复杂度爆炸 (TLE) for(int i = tt - 1;i < n;i++) temp.push_back(v[i]); sort(...); 每个工具都重新截取区间并排序，时间复杂度高达 $O(M \cdot N \log N)$。在 $3 \times 10^5$ 数据下必然超时。必须改为 离线增量维护。
2. 语法与STL误用 sort(temp.begin(),temp.end()),cmp; 逗号运算符导致 cmp 未被传入 sort，实际按结构体默认规则排序。应改为 sort(..., cmp);。
auto it = upper_bound(zz); 缺少必需的 [begin, end) 迭代器范围参数，且未传比较器，编译直接报错。
3. 贪心逻辑缺失 cout<<*it<<endl; 题目要求输出 单行总价值，代码仅打印每次匹配的节点结构体，未累加 ans，输出格式不符。
4. 状态未去重 全程无删除/标记操作 暗器被选中后未被移除，同一件高价值暗器可能被多个工具重复“修复”，严重违反“每件暗器只能用一次”的题意。

💡 解题思路

本题属于经典的 “双限制条件最大权匹配”，正解需打破“每次工具独立处理”的思维定势，采用 离线贪心 + 动态候选集：

  1. 排序定序：将工具按编号下限 $t$ 从大到小排序。$t$ 越大，能修的暗器越少（门槛高），优先处理可防止高价值暗器被低门槛工具“抢走”。
  2. 增量维护：暗器按编号降序排列。遍历工具时，因 $t$ 单调递减，满足 编号 >= t 的暗器集合只会 不断扩大。用指针将新符合条件的暗器 价值 插入 multiset，避免重复遍历。
  3. 贪心选择与去重：对当前工具的价值上限 $z$，在 multiset 中用 upper_bound(z) 定位第一个 $>z$ 的值，其前驱 prev(it) 即为合法最大价值。选中后 必须 erase 该迭代器（确保暗器消耗），并累加答案。
  4. 复杂度：排序 $O(N \log N + M \log M)$，multiset 操作均摊 $O(\log N)$，总复杂度 $O((N+M) \log N)$，完美契合时限。

📝 题意概括

  • 输入 K 个整数，求连续子序列的最大和。

🛠 题型模板与核心思路

题型归类：二叉树遍历序列还原 + 层序输出
核心逻辑：

  1. 后序定根：后序序列的最后一个元素一定是当前子树的根节点。
  2. 中序分左右：在中序序列中找到根节点，其左侧为左子树的中序区间，右侧为右子树的中序区间。

📖 题意概括

给定一个包含 $N$ 个节点和 $N-1$ 条边的无向图。若该图连通（即构成一棵树），请找出所有能使树高最大的根节点（Deepest Root），按编号升序输出。若图不连通，则统计连通分量个数 $K$，输出 Error: K components。

🛠 题型总结与通用模板

核心考点：图的连通性判定 + 树的直径性质 + DFS/BFS 遍历
经典结论：对于一棵树，从任意节点 $u$ 出发 DFS 得到的最远节点集合 $S_1$，与从 $S_1$ 中任意节点出发 DFS 得到的最远节点集合 $S_2$，它们的并集即为所有可能的“最深根”。

  2. 两遍DFS找根：
    • 第一遍：任选起点（如 1）DFS，记录最大深度及对应节点集 $A$。
    • 第二遍：从 $A$ 中任取一点 DFS，记录最大深度及对应节点集 $B$。
    • 答案：$A \cup B$，利用 set 自动去重排序后输出。

📖 题意概括

给定一个长度为 N 的整数序列，判断它是否为某二叉搜索树（BST）或镜像 BST 的前序遍历序列。

  • 若是，首行输出 YES，第二行输出该树的后序遍历序列（空格分隔，行末无空格）。
  • 若否，输出 NO。
  • BST 定义：左子树所有节点 < 根，右子树所有节点 >= 根。镜像 BST 恰好相反（左 >= 根，右 < 根）。

🧩 题型模板 / 核心考点

本题属于 二叉树遍历性质 + 递归区间划分 经典题型。核心考点可归纳为以下模板逻辑：

  1. 前序定根：前序序列的第一个元素永远是当前子树的根节点。
  2. BST 性质划分：利用 BST 的单调性，可在剩余序列中明确切分出左子树区间和右子树区间。
  3. 合法性校验：划分后需验证右子树区间是否完全满足 BST 条件（镜像同理）。若不满足，说明该序列不是对应类型的前序。
  4. 后序收集：递归顺序为 左子树 → 右子树 → 根节点，在递归返回时将根节点压入结果数组，天然得到后序序列。

💡 解题思路

  1. 单次递归验证 + 后序生成
    定义函数 bool getPost(int root, int end, bool isMirror)：
    • root 为当前子树在前序数组中的起始下标，end 为结束下标。
    • 从左向右扫描找右子树起点 i（第一个不满足左子树条件的元素），从右向左扫描找左子树终点 j。
    • 关键校验：合法划分必须满足 i == j + 1。若不满足，说明存在元素既不属于左也不属于右，直接返回 false。
    • 递归处理左区间 [root+1, i-1] 和右区间 [i, end]。若均合法，则将 pre[root] 加入 post 数组，返回 true。
  2. 双策略尝试
    先以 isMirror = false（普通 BST）调用。若失败，清空 post 数组，再以 isMirror = true 调用。两者皆失败则输出 NO。
  3. 复杂度：时间 O(N)，空间 O(N)（递归栈+结果数组），完美契合 N ≤ 1000 的限制。
